## Finding
The public call-for-speakers page listed 31 open calls dated 2026-11-08, but event identities and application details were deliberately hidden behind free registration. The anonymous page therefore does not provide the public event identity and actionable submission URL required by this tracker. This is a registration-wall limitation, not evidence that the site is dead.

## Tracker guidance
Do not create a parser, automate account creation, or bypass the wall. Revisit only through ordinary manual review if an anonymous listing later exposes event identities and direct application links, together with terms that permit the intended collection. Do not treat an old SpeakingGig listing as a live CFP; confirm the deadline and submission route on the organizer's site before adding or refreshing any note.
