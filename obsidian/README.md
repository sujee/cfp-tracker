# Obsidian assets

Example vault containing notes, templates, and views for CFP Tracker.

The refresh script populates `cfps/data` in a configured vault. This example includes sample CFP notes. Copy the other assets (talks, submissions, templates) into your vault as needed.

| Folder | Role |
|---|---|
| `cfps/data/` | Example CFP notes, grouped by deadline year. |
| `talks/` | Reusable talk notes. |
| `submissions/` | Submissions linked to talks and CFPs. |
| `templates/` | Templates for new CFPs, talks, and submissions. |
| `dashboard/` | Bases for CFPs, talks, and submissions, plus the CFP dashboard. |

## Required plugins

- **Bases** (core): Required for the `.base` files.
- **Dataview** (community): Required for `dashboard/cfps-dashboard.md`.
- **Templates** (core): Required for `templates/`. Set the template folder to `templates`.
